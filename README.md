# Adult Anime Release Watch

This repository builds a single RSS feed from selected release/news sources.

## Feed URL

Use this URL in Inoreader:

`https://raw.githubusercontent.com/zane6443/adult-anime-feed/main/feed.xml`

## Sources

- Lune Soft / Bunny Walker RSS
- Lune Soft / Bunny Walker OVA page
- Pink Pineapple official site
- PoRO official site

Some sites may block automated requests. Check `status.txt` after each run to see which sources worked.

## Updating

The GitHub Action runs every 6 hours. You can also run **Actions → Update feed → Run workflow** manually.
